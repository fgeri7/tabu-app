# Tabu Magyar v0.2.0

Mobil-first, offline PWA prototípus saját magyar kártyákkal.

## Deploy
A projekt statikus, ezért GitHub Pages-en közvetlenül futtatható. A repository gyökerét publikáld HTTPS-en, majd a publikus URL-t add meg a PWABuildernek.

## PWA
A manifest tartalmaz 192×192, 512×512, 512×512 maskable és 1024×1024 ikonokat. A maskable ikon fontos elemei középre vannak helyezve.

- index.html
- style.css
- app.js
